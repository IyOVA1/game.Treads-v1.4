# Treads

Modular tank builder & combat game.

## Local

```bash
npm install
npm run dev
```

## GitHub Pages

Repo: `game.Treads` → base path is already set to `/game.Treads/`

```bash
npm run build
npm install -D gh-pages
# add "deploy": "npm run build && gh-pages -d dist" to package.json scripts
npm run deploy
```

Site will be at: `https://YOUR_USERNAME.github.io/game.Treads/`
